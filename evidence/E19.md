# Chals AI Google Sheets Chat Add-on

Bound Apps Script sidebar for using `modeler_unified` from an existing Google
Sheet.

This add-on is intentionally a client adapter, not an agent. It reads bounded
evidence from the open workbook, creates a Chals Sheet Session, sends the
natural-language message to Chals, and executes deterministic readbacks when
the modeler requests a specific range. It can also execute the first durable
data bridge: promote a bounded Sheet range into a Chals CSV-backed dataset when
the modeler asks for that product step. The composer can attach verified PDFs
and images so `modeler_unified` can extract source facts and write them into the
open workbook. When the modeler publishes a BI view in Chals, the add-on can
also sync that published view into a deterministic `_Chals ...` tab in the same
Google Sheet.

It does not run an LLM, DuckDB, SQL or driver materialization inside Google
Sheets. Published BI views are executed in Chals; Apps Script only writes the
returned bounded table into the workbook.

The sidebar shows a read-only summary of Chals-managed data sources. It asks
`Code.gs` for workspace-scoped connection status with the stored workspace API
key and links to `Gestionar conexiones`. Authentication, table selection,
schedules and synchronization live exclusively in the deterministic web
product. `modeler_unified` starts only from stable BigQuery assets marked
`queryable=true`; it never connects to or refreshes external software.
